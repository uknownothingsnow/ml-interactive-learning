## 7.1 贝叶斯决策论

::: tip 📐 贝叶斯定理
贝叶斯定理是贝叶斯学派的基石，描述了在获得新证据后如何更新我们的信念。
:::

### 贝叶斯定理

$$P(c|\mathbf{x}) = \frac{P(\mathbf{x}|c) \cdot P(c)}{P(\mathbf{x})}$$

| 符号 | 含义 |
|------|------|
| $P(c\|\mathbf{x})$ | 后验概率 |
| $P(\mathbf{x}\|c)$ | 似然 |
| $P(c)$ | 先验概率 |
| $P(\mathbf{x})$ | 证据因子 |

::: info 核心思想
后验概率 = (似然 × 先验) / 证据。通过观察数据 $\mathbf{x}$，更新对类别 $c$ 的认知。
:::

### 贝叶斯判定准则

为最小化总体风险，贝叶斯判定准则选�使后验概率最大的类别：

$$h^*(\mathbf{x}) = \arg\max_c P(c|\mathbf{x})$$

等价于：

$$h^*(\mathbf{x}) = \arg\max_c P(\mathbf{x}|c) \cdot P(c)$$

::: tip ✓ 优势
- 理论最优（最小化期望风险）
- 融合先验知识
- 可解释性强
:::

::: warning ⚠️ 挑战
- 需要知道先验概率
- 需要估计类条件概率
- 计算复杂度可能很高
:::

## 7.2 极大似然估计

::: tip 📊 参数估计
极大似然估计（MLE）是频率学派估计参数的标准方法：**选择使观测数据出现概率最大的参数**。
:::

### 似然函数与对数似然

似然函数：

$$L(\theta) = P(D|\theta) = \prod_i P(\mathbf{x}_i|\theta)$$

对数似然：

$$\ell(\theta) = \log L(\theta) = \sum_i \log P(\mathbf{x}_i|\theta)$$

最大化得到参数估计：

$$\hat{\theta}_{MLE} = \arg\max_\theta \ell(\theta)$$

::: info 💡 为什么用对数？
将连乘变为求和，便于计算和优化，且不改变最优解。
:::

### MLE vs MAP

|  | 极大似然估计 (MLE) | 最大后验估计 (MAP) |
|--|----|----|
| **公式** | $\hat{\theta}_{MLE} = \arg\max P(D\|\theta)$ | $\hat{\theta}_{MAP} = \arg\max P(\theta\|D)$ |
| **学派** | 频率学派观点 | 贝叶斯学派观点 |
| **先验** | 不考虑先验知识 | 融合先验 $P(\theta)$ |
| **适用** | 数据充足时效果好 | 数据稀少时更稳健 |

## 7.3 朴素贝叶斯分类器

::: tip 🎭 "朴素"的假设
朴素贝叶斯分类器基于一个强假设：**属性条件独立性假设**。虽然这个假设在现实中往往不成立，但朴素贝叶斯在实践中表现出奇地好！
:::

### 条件独立性假设

完整的类条件概率：

$$P(\mathbf{x}|c) = P(x_1, x_2, \ldots, x_d | c)$$

参数数量随维度**指数增长**！

通过朴素假设简化后：

$$P(\mathbf{x}|c) = \prod_{i=1}^{d} P(x_i|c)$$

参数数量**线性增长**！

::: tip ✓ 为什么有效？
- 降低模型复杂度，避免过拟合
- 所需训练数据量大幅减少
- 训练和预测都非常快速
- 即使假设不完全成立，分类效果仍然不错
:::

::: warning ⚠️ 局限性
- 无法表达属性间的相关性
- 预测的概率值不够准确
- 特征高度相关时性能下降
:::

### 拉普拉斯修正

当训练集中某个属性值在某个类别下从未出现时，会导致**零概率问题**：整个后验概率都会变成 0！

**问题**：如果某个 $P(x_i|c) = 0$，则 $P(c|\mathbf{x}) = 0 \times \ldots = 0$。一个零值毁掉整个结果！

**解决方案**：拉普拉斯修正（加1平滑）：

$$\hat{P}(x_i|c) = \frac{N_{ic} + 1}{N_c + N_i}$$

确保所有概率都非零。

## 7.4 半朴素贝叶斯分类器

::: tip 🔓 放松独立性假设
半朴素贝叶斯分类器适当考虑一部分属性间的相互依赖信息，在**模型复杂度**和**分类性能**之间寻求平衡。
:::

| 方法 | 全称 | 说明 |
|------|------|------|
| SPODE | Super-Parent ODE | 所有属性依赖于同一个超父属性 |
| TAN | Tree Augmented Naive Bayes | 属性间形成树状依赖结构 |
| AODE | Averaged ODE | 集成多个SPODE模型 |

::: info 核心思想
在朴素贝叶斯（完全独立）和贝叶斯网（任意依赖）之间找到平衡点。
:::

## 7.5 贝叶斯网

::: tip 🕸️ 概率图模型
**贝叶斯网**（Bayesian Network）借助有向无环图(DAG)来刻画属性之间的依赖关系，并使用条件概率表(CPT)来描述属性的联合概率分布。
:::

### 贝叶斯网的组成

**1. 结构（网络拓扑）**：
- 节点表示随机变量
- 有向边表示依赖关系
- 必须是有向无环图(DAG)
- 父节点影响子节点

**2. 参数（CPT）**：
- 每个节点有条件概率表
- $P(X|\text{Parents}(X))$
- 根节点只有先验概率
- 通过数据学习参数

联合概率分解：

$$P(x_1, \ldots, x_n) = \prod_{i=1}^{n} P(x_i | \text{Parents}(x_i))$$

### 推断与学习

|  | 推断问题 | 学习问题 |
|--|----------|----------|
| **目标** | 给定证据变量的观测值，计算查询变量的后验概率分布 | 从数据中学习贝叶斯网的结构和参数 |
| **方法** | 精确推断：变量消除；近似推断：吉布斯采样 | 参数学习：MLE/MAP；结构学习：评分搜索 |
