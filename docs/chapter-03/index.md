## 3.1 线性回归 (Linear Regression)

::: tip 📊 什么是线性回归？
线性回归试图学习一个线性函数来拟合数据，是最简单但也最常用的回归模型。给定数据集 D，线性回归试图学到一个函数来映射输入和输出的关系：

$$f(x) = wx + b$$

其中 **w** 是权重（斜率），**b** 是偏置（截距）。我们的目标是找到最优的 w 和 b，使得预测值 $f(x)$ 尽可能接近真实值 $y$。
:::

::: info 📐 均方误差损失 (MSE Loss)
我们使用均方误差（Mean Squared Error）来衡量模型的好坏：

$$L(w, b) = \frac{1}{n} \sum_{i=1}^{n} (y_i - f(x_i))^2$$
:::

**为什么用平方？**
- 确保误差总是正数
- 惩罚大的误差更严重
- 数学性质良好，易于求导

**最小二乘法：** 通过令损失函数的导数为 0，可以直接求出解析解（闭式解）。

## 3.2 梯度下降 (Gradient Descent)

::: tip 🎯 优化的艺术
梯度下降是机器学习中最重要的优化算法。它的核心思想非常直观：**沿着函数下降最快的方向（负梯度方向）移动**，逐步逼近最优解。
:::

### 更新规则

$$\theta \leftarrow \theta - \alpha \cdot \frac{\partial L}{\partial \theta}$$

| 符号 | 含义 |
|------|------|
| $\theta$ (theta) | 待优化的参数 |
| $\alpha$ (alpha) | 学习率（步长） |
| $\frac{\partial L}{\partial \theta}$ | 损失函数的梯度 |

::: tip ✓ 梯度下降的优势
- 适用于高维问题
- 不需要矩阵求逆
- 可处理大规模数据
- 容易并行化
:::

::: warning ⚠️ 学习率的选择
- **太小**：收敛缓慢
- **太大**：可能震荡或发散
- **建议**：从小开始逐步调整
:::

### 代码实践：实现梯度下降

```python
def gradient_descent(learning_rate, num_iterations):
    """
    使用梯度下降优化 f(x) = x^2

    参数:
        learning_rate: 学习率
        num_iterations: 迭代次数

    返回:
        x: 最终的 x 值
        history: 优化过程中的 x 值列表
    """
    x = 10.0  # 初始值
    history = [x]

    for i in range(num_iterations):
        # 计算梯度 df/dx = 2x
        gradient = 2 * x

        # 更新 x 值
        x = x - learning_rate * gradient

        history.append(x)

    return x, history

# 测试代码
final_x, path = gradient_descent(learning_rate=0.1, num_iterations=20)
print(f"最终 x 值: {final_x:.6f}")
print(f"最终 f(x) 值: {final_x**2:.6f}")
print(f"优化路径长度: {len(path)}")
```

## 3.3 逻辑回归 (Logistic Regression)

::: tip 🔄 从回归到分类
尽管名字里有"回归"，但逻辑回归实际上是一个**分类算法**。它通过 Sigmoid 函数将线性模型的输出映射到 (0, 1) 区间，表示样本属于正类的概率。
:::

### Sigmoid 函数

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

其中 $z = w_1 \cdot x_1 + w_2 \cdot x_2 + \ldots + b$（线性组合）

| 条件 | 结果 |
|------|------|
| $z \to +\infty$ | $\sigma(z) \to 1$ |
| $z = 0$ | $\sigma(z) = 0.5$ |
| $z \to -\infty$ | $\sigma(z) \to 0$ |

::: info ✂️ 决策边界
当 $\sigma(z) = 0.5$ 时，即 $z = 0$，这就是决策边界。对于二维特征空间，决策边界是一条直线：$w_1 \cdot x_1 + w_2 \cdot x_2 + b = 0$。这条线将空间划分为两个区域，分别对应两个类别。
:::

### 交互式演示

调整权重和偏置参数，观察决策边界如何移动。背景颜色表示分类概率：蓝色表示倾向于正类，红色表示倾向于负类。虚线是 P=0.5 的决策边界。

## 3.4 正则化 (Regularization)

::: tip 🛡️ 防止过拟合的利器
正则化通过在损失函数中添加惩罚项来限制模型复杂度，防止过拟合。两种最常用的正则化方法是 L1 和 L2 正则化。
:::

### L2 正则化（Ridge）

$$L = L_0 + \lambda \cdot \sum w_i^2$$

- 惩罚权重的平方和
- 倾向于产生小但非零的权重
- 适合特征之间相关性高的情况
- 解析解存在（可直接求解）

### L1 正则化（Lasso）

$$L = L_0 + \lambda \cdot \sum |w_i|$$

- 惩罚权重的绝对值和
- 倾向于产生稀疏解（很多权重为 0）
- 可用于特征选择
- 更具解释性

::: warning ⚖️ 正则化系数 λ (lambda)
**λ** 控制正则化的强度：
- **λ = 0**：无正则化，可能过拟合
- **λ 太大**：欠拟合，模型过于简单
- **λ 适中**：在偏差和方差之间取得平衡
:::

::: info 📐 L1 vs L2：几何直观
**L2: 圆形约束** — 在参数空间中，L2 正则化的约束区域是一个圆（或高维的球）。损失函数等高线与圆的切点通常不在坐标轴上，所以权重不会变成 0。

**L1: 菱形约束** — L1 正则化的约束区域是菱形（或高维的超菱形）。等高线更容易在菱形的顶点（坐标轴）处相交，导致某些权重精确为 0。
:::

## 📝 本章小结

::: tip 总结
- ✅ 线性回归通过最小化均方误差学习线性函数，可用解析解或梯度下降求解
- ✅ 梯度下降是核心的优化算法，沿负梯度方向迭代更新参数
- ✅ 学习率是关键超参数，需要仔细调整以平衡收敛速度和稳定性
- ✅ 逻辑回归使用 Sigmoid 函数将线性输出映射为概率，用于二分类问题
- ✅ 正则化（L1/L2）通过惩罚项控制模型复杂度，防止过拟合
- ✅ L1 倾向于稀疏解（特征选择），L2 倾向于权重衰减
:::
