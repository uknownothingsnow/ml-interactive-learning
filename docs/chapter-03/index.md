## 3.1 线性回归 (Linear Regression)

::: tip 📊 什么是线性回归？
线性回归试图学习一个线性函数来拟合数据，是最简单但也最常用的回归模型。给定数据集 D，线性回归试图学到一个函数来映射输入和输出的关系：

$$f(x) = wx + b$$

其中 **w** 是权重（斜率），**b** 是偏置（截距）。我们的目标是找到最优的 w 和 b，使得预测值 $f(x)$ 尽可能接近真实值 $y$。
:::

::: info 📐 均方误差损失 (MSE Loss)
我们使用均方误差（Mean Squared Error）来衡量模型的好坏：

$$L(w, b) = \frac{1}{n} \sum_{i=1}^{n} (y_i - f(x_i))^2$$
:::

**为什么用平方？**
- 确保误差总是正数
- 惩罚大的误差更严重
- 数学性质良好，易于求导

**最小二乘法：** 通过令损失函数的导数为 0，可以直接求出解析解（闭式解）。

## 3.2 梯度下降 (Gradient Descent)

::: tip 🎯 优化的艺术
梯度下降是机器学习中最重要的优化算法。它的核心思想非常直观：**沿着函数下降最快的方向（负梯度方向）移动**，逐步逼近最优解。
:::

### 更新规则

$$\theta \leftarrow \theta - \alpha \cdot \frac{\partial L}{\partial \theta}$$

| 符号 | 含义 |
|------|------|
| $\theta$ (theta) | 待优化的参数 |
| $\alpha$ (alpha) | 学习率（步长） |
| $\frac{\partial L}{\partial \theta}$ | 损失函数的梯度 |

::: tip ✓ 梯度下降的优势
- 适用于高维问题
- 不需要矩阵求逆
- 可处理大规模数据
- 容易并行化
:::

::: warning ⚠️ 学习率的选择
- **太小**：收敛缓慢
- **太大**：可能震荡或发散
- **建议**：从小开始逐步调整
:::

### 代码实践：实现梯度下降

```python
def gradient_descent(learning_rate, num_iterations):
    """
    使用梯度下降优化 f(x) = x^2

    参数:
        learning_rate: 学习率
        num_iterations: 迭代次数

    返回:
        x: 最终的 x 值
        history: 优化过程中的 x 值列表
    """
    x = 10.0  # 初始值
    history = [x]

    for i in range(num_iterations):
        # 计算梯度 df/dx = 2x
        gradient = 2 * x

        # 更新 x 值
        x = x - learning_rate * gradient

        history.append(x)

    return x, history

# 测试代码
final_x, path = gradient_descent(learning_rate=0.1, num_iterations=20)
print(f"最终 x 值: {final_x:.6f}")
print(f"最终 f(x) 值: {final_x**2:.6f}")
print(f"优化路径长度: {len(path)}")
```

## 3.3 逻辑回归 (Logistic Regression)

::: tip 🔄 从回归到分类
尽管名字里有"回归"，但逻辑回归实际上是一个**分类算法**。它通过 Sigmoid 函数将线性模型的输出映射到 (0, 1) 区间，表示样本属于正类的概率。
:::

### Sigmoid 函数

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

其中 $z = w_1 \cdot x_1 + w_2 \cdot x_2 + \ldots + b$（线性组合）

| 条件 | 结果 |
|------|------|
| $z \to +\infty$ | $\sigma(z) \to 1$ |
| $z = 0$ | $\sigma(z) = 0.5$ |
| $z \to -\infty$ | $\sigma(z) \to 0$ |

::: info ✂️ 决策边界
当 $\sigma(z) = 0.5$ 时，即 $z = 0$，这就是决策边界。对于二维特征空间，决策边界是一条直线：$w_1 \cdot x_1 + w_2 \cdot x_2 + b = 0$。这条线将空间划分为两个区域，分别对应两个类别。
:::

### 交互式演示

调整权重和偏置参数，观察决策边界如何移动。背景颜色表示分类概率：蓝色表示倾向于正类，红色表示倾向于负类。虚线是 P=0.5 的决策边界。

## 3.4 线性判别分析 (Linear Discriminant Analysis)

::: tip 📐 Fisher 判别的思想
线性判别分析（LDA）的核心思想是：将样本投影到一条直线上，使得**同类样本的投影尽可能近**（类内散度小），**异类样本的投影尽可能远**（类间散度大）。
:::

### 散度矩阵

给定数据集 $D = \{(\mathbf{x}_i, y_i)\}$，其中 $y_i \in \{0, 1\}$，定义：

- 第 $i$ 类的均值向量：$\boldsymbol{\mu}_i = \frac{1}{|X_i|}\sum_{\mathbf{x} \in X_i} \mathbf{x}$
- **类内散度矩阵**：$\mathbf{S}_w = \sum_{i=0}^{1} \sum_{\mathbf{x} \in X_i} (\mathbf{x} - \boldsymbol{\mu}_i)(\mathbf{x} - \boldsymbol{\mu}_i)^T$
- **类间散度矩阵**：$\mathbf{S}_b = (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)^T$

### 最优投影方向

LDA 的目标是最大化**广义瑞利商**：

$$J(\mathbf{w}) = \frac{\mathbf{w}^T \mathbf{S}_b \mathbf{w}}{\mathbf{w}^T \mathbf{S}_w \mathbf{w}}$$

即最大化类间散度与类内散度的比值。通过拉格朗日乘子法，最优解为：

$$\mathbf{w}^* = \mathbf{S}_w^{-1}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)$$

::: info 🔍 LDA vs PCA

| 比较维度 | LDA | PCA |
|----------|-----|-----|
| 类型 | **监督**降维 | **无监督**降维 |
| 目标 | 最大化类别可分性 | 最大化数据方差 |
| 利用标签 | ✅ 是 | ❌ 否 |
| 最大维度 | 类别数 - 1 | 不受限 |
| 适用场景 | 分类预处理 | 通用降维 |
:::

## 3.5 多分类学习

::: tip 🎯 从二分类到多分类
现实中很多问题涉及多个类别（如手写数字识别有 0-9 共 10 类）。基本思路是将多分类任务**拆解为若干个二分类任务**来求解。
:::

### 拆分策略

| 策略 | 全称 | 训练分类器数 | 思想 |
|------|------|-------------|------|
| **OvO** | One-vs-One | $\frac{N(N-1)}{2}$ | 每两个类别训练一个分类器，投票决定 |
| **OvR** | One-vs-Rest | $N$ | 每个类别 vs 其余所有类别 |
| **MvM** | Many-vs-Many | 由编码矩阵决定 | 多个类别分为两组，多次划分 |

<div class="info-grid">
<div class="info-card">

**OvO（一对一）**

- 训练 $N(N-1)/2$ 个分类器
- 每个分类器只用两个类别的数据
- 预测时投票：票数最多的类别胜出
- ✅ 训练速度快（每个分类器数据量小）
- ⚠️ 分类器数量多

</div>
<div class="info-card">

**OvR（一对其余）**

- 训练 $N$ 个分类器
- 每个分类器用一个类别 vs 其余全部
- 预测时选置信度最高的分类器
- ✅ 分类器数量少
- ⚠️ 训练数据不平衡

</div>
</div>

::: info 📦 纠错输出码 (ECOC)
ECOC 是 MvM 的一种实现。对 $N$ 个类别进行 $M$ 次划分，每次将类别分为正类和反类（编码矩阵），训练 $M$ 个分类器。预测时将测试样本的 $M$ 个预测结果组成**编码**，与各类别的编码比较，选择**海明距离**或**欧氏距离**最近的类别。

ECOC 具有一定的**纠错能力**：即使某个分类器出错，仍可能通过编码冗余得到正确的分类结果。
:::

## 3.6 类别不平衡问题

::: warning ⚖️ 当数据不平衡时
在很多实际场景中，不同类别的样本数量差距悬殊（如欺诈检测中，正常交易远多于欺诈交易）。此时分类器倾向于将所有样本预测为多数类，导致少数类的识别能力很差。
:::

### 应对策略

| 策略 | 方法 | 说明 |
|------|------|------|
| **欠采样** | 减少多数类样本 | 随机丢弃多数类样本，使两类数量接近。缺点：可能丢失重要信息。代表方法：EasyEnsemble |
| **过采样** | 增加少数类样本 | 复制或合成少数类样本。代表方法：**SMOTE**（在少数类样本之间插值生成新样本） |
| **阈值移动** | 调整决策阈值 | 不改变数据，将决策阈值从 0.5 调整为 $\frac{m^+}{m^-}$，使决策面向少数类偏移 |

::: info 💡 代价敏感学习
另一种思路是为不同类型的错误赋予不同的**代价**（misclassification cost）。例如，在医疗诊断中，漏诊的代价远高于误诊。通过代价矩阵，让模型在训练时考虑错误的不对称性：

$$\text{最小化} \quad \sum_{i} C(y_i, \hat{y}_i) \cdot \mathbb{1}[y_i \neq \hat{y}_i]$$

其中 $C(y_i, \hat{y}_i)$ 是将类别 $y_i$ 误判为 $\hat{y}_i$ 的代价。
:::

## 3.7 正则化 (Regularization)

::: tip 🛡️ 防止过拟合的利器
正则化通过在损失函数中添加惩罚项来限制模型复杂度，防止过拟合。两种最常用的正则化方法是 L1 和 L2 正则化。
:::

### L2 正则化（Ridge）

$$L = L_0 + \lambda \cdot \sum w_i^2$$

- 惩罚权重的平方和
- 倾向于产生小但非零的权重
- 适合特征之间相关性高的情况
- 解析解存在（可直接求解）

### L1 正则化（Lasso）

$$L = L_0 + \lambda \cdot \sum |w_i|$$

- 惩罚权重的绝对值和
- 倾向于产生稀疏解（很多权重为 0）
- 可用于特征选择
- 更具解释性

::: warning ⚖️ 正则化系数 λ (lambda)
**λ** 控制正则化的强度：
- **λ = 0**：无正则化，可能过拟合
- **λ 太大**：欠拟合，模型过于简单
- **λ 适中**：在偏差和方差之间取得平衡
:::

::: info 📐 L1 vs L2：几何直观
**L2: 圆形约束** — 在参数空间中，L2 正则化的约束区域是一个圆（或高维的球）。损失函数等高线与圆的切点通常不在坐标轴上，所以权重不会变成 0。

**L1: 菱形约束** — L1 正则化的约束区域是菱形（或高维的超菱形）。等高线更容易在菱形的顶点（坐标轴）处相交，导致某些权重精确为 0。
:::

## 📝 本章小结

::: tip 总结
- ✅ 线性回归通过最小化均方误差学习线性函数，可用解析解或梯度下降求解
- ✅ 梯度下降是核心的优化算法，沿负梯度方向迭代更新参数
- ✅ 学习率是关键超参数，需要仔细调整以平衡收敛速度和稳定性
- ✅ 逻辑回归使用 Sigmoid 函数将线性输出映射为概率，用于二分类问题
- ✅ LDA 通过最大化类间散度与类内散度之比寻找最优投影方向
- ✅ 多分类学习可通过 OvO、OvR、ECOC 等拆分策略实现
- ✅ 类别不平衡可通过欠采样、过采样（SMOTE）、阈值移动或代价敏感学习应对
- ✅ 正则化（L1/L2）通过惩罚项控制模型复杂度，防止过拟合
- ✅ L1 倾向于稀疏解（特征选择），L2 倾向于权重衰减
:::
