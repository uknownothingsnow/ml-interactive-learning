## 6.1 间隔与支持向量

::: tip 📏 为什么要最大化间隔？
在线性可分的情况下，能够正确划分训练样本的超平面有无穷多个。**支持向量机**的核心思想是找到具有**"最大间隔"**的划分超平面。
:::

### 超平面与间隔

超平面方程：

$$\mathbf{w} \cdot \mathbf{x} + b = 0$$

样本到超平面的距离：

$$r = \frac{|\mathbf{w} \cdot \mathbf{x} + b|}{\|\mathbf{w}\|}$$

间隔（margin）：

$$\gamma = \frac{2}{\|\mathbf{w}\|}$$

::: tip ✓ 为什么最大化间隔？
- 更好的泛化能力
- 对噪声更鲁棒
- VC维理论支持
:::

::: info 🎯 支持向量
距离超平面最近的训练样本点称为**支持向量**。它们"支撑"着这个间隔，决定了最优分类超平面。
:::

### SVM优化目标

SVM的优化目标是找到使间隔最大化的 $\mathbf{w}$ 和 $b$：

最大化：

$$\gamma = \frac{2}{\|\mathbf{w}\|}$$

等价于最小化：

$$\frac{1}{2}\|\mathbf{w}\|^2$$

约束条件：

$$y_i(\mathbf{w} \cdot \mathbf{x}_i + b) \geq 1, \quad \forall i$$

这是一个**凸二次规划问题**，存在全局最优解，可以通过现有的QP优化算法求解。

## 6.2 对偶问题

::: tip 🔄 为什么要引入对偶问题？
通过拉格朗日乘子法，我们可以将原始问题转化为对偶问题，这样做有几个重要优势：

- 🚀 **更易求解**：对偶问题往往更容易优化
- 🔑 **引入核函数**：为核技巧提供基础
- 📊 **稀疏解**：大部分 α 为 0
:::

### 对偶问题公式

最大化：

$$L(\alpha) = \sum_i \alpha_i - \frac{1}{2}\sum_i\sum_j \alpha_i \alpha_j y_i y_j \mathbf{x}_i \cdot \mathbf{x}_j$$

约束条件：

$$\sum_i \alpha_i y_i = 0, \quad \alpha_i \geq 0, \quad \forall i$$

::: info 📐 KKT条件
支持向量机的解需要满足**KKT（Karush-Kuhn-Tucker）条件**：

① $\alpha_i \geq 0$ — 对偶变量非负

② $y_i(\mathbf{w} \cdot \mathbf{x}_i + b) - 1 \geq 0$ — 原始约束满足

③ $\alpha_i[y_i(\mathbf{w} \cdot \mathbf{x}_i + b) - 1] = 0$ — **互补松弛条件（关键！）**

**互补松弛条件**表明：只有支持向量对应的 $\alpha_i > 0$，其他样本的 $\alpha_i = 0$。这就是为什么SVM的解是**稀疏的**！
:::

## 6.3 核函数

::: tip 🎩 核技巧（Kernel Trick）
现实任务中，样本空间往往不是线性可分的。**核技巧**的思想是：将样本映射到更高维的特征空间，使其在高维空间中线性可分。
:::

### 传统方法 vs 核技巧

**传统方法**：
1. 显式计算映射 $\phi(\mathbf{x})$
2. 在高维空间计算内积 $\phi(\mathbf{x}_i) \cdot \phi(\mathbf{x}_j)$
3. ❌ 问题：维度可能极高，甚至无穷维！

**核技巧**：
1. 直接定义核函数 $K(\mathbf{x}_i, \mathbf{x}_j)$
2. $K(\mathbf{x}_i, \mathbf{x}_j) = \phi(\mathbf{x}_i) \cdot \phi(\mathbf{x}_j)$
3. ✅ 无需显式计算 $\phi(\mathbf{x})$！

::: info 核函数定理
只要一个对称函数满足正定性，它就对应某个映射 $\phi$ 的内积。这意味着我们可以直接设计核函数，而无需知道具体的映射形式！
:::

## 6.4 软间隔与正则化

::: tip 🛡️ 软间隔SVM
现实任务中，数据往往不是完全线性可分的，可能存在**噪声**或**离群点**。**软间隔**允许某些样本不满足约束条件。
:::

### 软间隔优化目标

最小化：

$$\frac{1}{2}\|\mathbf{w}\|^2 + C \sum_i \xi_i$$

约束条件：

$$y_i(\mathbf{w} \cdot \mathbf{x}_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0$$

- **$\xi_i$（松弛变量）**：允许样本违反约束的程度
- **C（惩罚参数）**：控制对误分类的惩罚强度

| C 值 | 行为 | 风险 |
|------|------|------|
| C → 0 | 容忍更多误分类，间隔更大 | 可能欠拟合 |
| C 适中 | 平衡间隔与误差，泛化能力好 | 通常最优 |
| C → ∞ | 接近硬间隔，追求完美分类 | 可能过拟合 |

### 损失函数视角

软间隔SVM可以从**损失函数+正则化**的角度理解：

$$\min \left[\sum_i \ell(y_i, f(\mathbf{x}_i)) + \lambda \|\mathbf{w}\|^2\right]$$

**Hinge损失**：

$$\ell(y, f(\mathbf{x})) = \max(0, 1 - y \cdot f(\mathbf{x}))$$

- $y \cdot f(\mathbf{x}) \geq 1$: 损失为 0（正确且确信）
- $y \cdot f(\mathbf{x}) < 1$: 线性增长（惩罚违反间隔）

**正则化项** $\lambda\|\mathbf{w}\|^2$ 控制模型复杂度，防止过拟合，其中 $\lambda = 1/(2C)$。

## 6.5 支持向量回归 (SVR)

::: tip 📈 从分类到回归
SVM不仅可以用于分类，还可以用于回归任务。**支持向量回归（SVR）**的思想是找一个函数，使得大部分样本点都落在以 $f(\mathbf{x})$ 为中心、宽度为 $2\varepsilon$ 的"管道"内。
:::

### SVR优化目标

最小化：

$$\frac{1}{2}\|\mathbf{w}\|^2 + C \sum_i (\xi_i + \xi_i^*)$$

约束条件：

$$f(\mathbf{x}_i) - y_i \leq \varepsilon + \xi_i$$

$$y_i - f(\mathbf{x}_i) \leq \varepsilon + \xi_i^*$$

$$\xi_i, \xi_i^* \geq 0$$

**ε-不敏感损失**：
- $|y - f(\mathbf{x})| \leq \varepsilon$: 损失为 0
- $|y - f(\mathbf{x})| > \varepsilon$: 线性惩罚

**参数说明**：ε 为容忍误差（管道宽度），C 为惩罚参数，$\xi, \xi^*$ 为松弛变量。

::: tip ⭐ SVR的优势
- 对异常值鲁棒（ε-不敏感）
- 稀疏解，预测高效
- 可通过核函数处理非线性
- 泛化能力强
:::

::: warning ⚠️ SVR的挑战
- 参数（C, ε, 核参数）选择困难
- 大规模数据集训练慢
- 需要选择合适的核函数
:::

## 📝 本章小结

::: tip 总结
- ✅ 支持向量机通过最大化间隔寻找最优分类超平面，具有良好的泛化能力
- ✅ 对偶问题和KKT条件保证了SVM解的稀疏性，只有支持向量对应的α非零
- ✅ 核技巧允许在不显式计算高维映射的情况下，处理非线性可分问题
- ✅ 软间隔SVM通过引入松弛变量和惩罚参数C，可以处理噪声和不完全可分数据
- ✅ SVR将SVM思想扩展到回归任务，使用ε-不敏感损失函数实现鲁棒回归
- ✅ RBF核是最常用的核函数，适合大多数实际应用场景
:::
